# Otmetki Core

Небольшая независимая учебная основа для предметов, курсов, материалов, заданий и правил начисления баллов. Материалы сохраняются по версиям; из выбранных версий можно получить текстовый контекст с источниками и без точных повторов.

Это самостоятельная учебная часть проекта для совместной разработки: каталог курсов, материалы, задания и сборка текстового контекста. Пакет предназначен для встраивания в приложение; рабочая платформа и её закрытые интеграции развиваются отдельно.

## Что работает

- Каталог предметов и курсов отдельно для направлений `management` и `economics`.
- Темы курса, текстовые материалы, задания и правила возможных учебных баллов.
- Новая версия материала при каждой правке и чтение предыдущей версии.
- Проверка ожидаемой версии при сохранении, чтобы не затереть чужую правку.
- Консервативное удаление точных повторов только в экспортируемом контексте, с сохранением всех ссылок на источники.
- Локальный HTTP API и адаптивная демонстрационная страница.

Пакет принимает уже подготовленные текстовые блоки. Загрузки PDF или Word, OCR, внешнего скачивания, моделей ИИ, чатов и распознавания фотографий здесь нет. HTTPS-ссылка хранится как метаданные, а её содержимое автоматически не загружается.

## Быстрый запуск

Нужны Python 3.11 или новее и SQLite из стандартной библиотеки Python с поддержкой `json_valid`. Внешние зависимости для запуска не требуются.

Из корня этого пакета:

```sh
PYTHONPATH=src python3 -m otmetki_core demo
PYTHONPATH=src python3 -m otmetki_core serve
```

Откройте `http://127.0.0.1:8088`. Демонстрация использует только вымышленные записи; даты работ в ней не определены. Команда `demo` не добавляет примеры в уже непустой каталог предметов.

По умолчанию база находится в `.data/demo.sqlite3`. Для другого файла и порта:

```sh
PYTHONPATH=src python3 -m otmetki_core --database .data/example.sqlite3 demo
PYTHONPATH=src python3 -m otmetki_core --database .data/example.sqlite3 serve --port 8089
```

**Демонстрационный сервер предназначен только для локальной разработки.** У него нет входа пользователей или проверки прав на записи. Он привязывается к loopback и проверяет Host/Origin; публиковать его через туннель или обратный прокси нельзя. При встраивании в приложение все проверки доступа выполняет приложение до вызова ядра.

## Использование как библиотеки

```python
from otmetki_core import Store, context_txt

with Store(":memory:") as store:
    subject = store.create_subject({
        "code": "example-models",
        "title": "Линейные модели · пример",
    })
    course = store.create_course({
        "subjectId": subject["id"],
        "direction": "management",
        "cohort": "DEMO-M",
        "semester": 1,
    })
    material = store.create_material({
        "courseId": course["id"],
        "title": "Учебный пример",
        "blocks": [{"id": "formula", "kind": "formula", "text": "y = a + b x"}],
    })
    selection = [{"id": material["id"], "version": material["version"]}]
    print(context_txt(store.context_materials(selection)))
```
