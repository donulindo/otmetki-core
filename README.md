# MSU — отметки на парах, расписание, материалы, задания и формы

Открытая часть учебного пространства: сайт и Telegram Mini App, материалы и их версии, общие библиотеки групп и потоков, беседы с ИИ и репетитор, обработка документов, обратная связь и ручной календарь.

Основная учебная аудитория — первый курс экономического факультета МГУ: экономика и менеджмент. Готовность функций определяется для конкретного профиля. Поддержка остальных курсов и факультетов развивается отдельно.

## Приложение

Полное самостоятельное приложение — в [app](app/README.md). Node.js 22.13+, Python 3.11+, собственные ключи разработчика; без ИИ библиотека тоже работает. Исходные данные создаются локально. Для первого запуска выполните инструкции в app/README.md.

## Небольшая Python-библиотека

Сохранена независимая учебная основа `src/otmetki_core`: SQLite, версии материалов, сборка контекста с источниками и локальный демонстрационный интерфейс.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m otmetki_core --help
.venv/bin/python -m unittest discover -s tests
```

## Разработка

Документация открытых компонентов находится в `docs`. Предложения принимаются через GitHub. Для принятия предложения нужны подтверждённый статус разработчика, проверка актуальной версии и отдельное решение владельца. Само создание предложения или чтение кода статуса не даёт.

Закрытые учебные автоматизации, внутренние спецификации, рабочие данные и настройки инфраструктуры отсутствуют. Публикация исходников не означает обновление работающего сервиса. Apache 2.0; сторонние шрифты — по приложенным OFL.
