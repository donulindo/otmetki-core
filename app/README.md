# MSU — учебное пространство

Самостоятельный сайт и Telegram Mini App: библиотека с оригиналами и версиями, общие материалы групп и потоков, личные беседы, репетитор, обработка документов, обратная связь и ручной календарь. Основная учебная аудитория — первый курс ЭФ МГУ. Примеры вымышлены; материалов, баз и ключей работающего сервиса здесь нет.

## Запуск

Нужны Node.js 22.13+ и Python 3.11+. Из каталога `app`:

```sh
npm ci
python3 -m venv .venv
.venv/bin/python -m pip install -r server/requirements.txt
node tools/bootstrap.mjs
npm run build
npm start
```

Откройте http://127.0.0.1:3000. Однократно созданный локальный ключ находится в `.data/access-key.txt`. Скрипт не заменяет существующий env. Для примеров: `npm run demo`.

Материалы работают без ИИ. Для ИИ заполните собственные `OPENAI_API_KEY`, при необходимости `OPENAI_BASE_URL` и идентификаторы доступных вам моделей `MODEL_SOL_ID`, `MODEL_LUNA_ID` в `.env.local`. При изменении порта задайте PREVIEW_ORIGIN точно равным адресу в браузере. Sol и Luna — названия двух режимов в интерфейсе; действительные модели задаёт оператор. Вызовы тарифицируются вашим провайдером. Ключи читаются только сервером. Внешние ссылки автоматически не скачиваются.

## Доступ

Локальный ключ открывает только профиль оператора. Вход дополнительных участников выключен по умолчанию. Для отдельной тестовой установки настройте собственный Telegram-бот, его токен и числовой ID владельца; участники должны быть подтверждены оператором и явно включены в аудитории. Только после отдельной настройки включайте `PREVIEW_ENABLE_PARTICIPANTS=true`. Имя, введённое в форме, доступа не даёт. Подпись Telegram проверяется сервером.

## Проверка

```sh
npm run typecheck
npm test
npm run test:client
cd server
../.venv/bin/python -m unittest test_extract.py
```

Тесты создают отдельные временные базы, синтетические документы и искусственные потоки. Не вызывают реальный ИИ. UI использует одну адаптивную компоновку в браузере и Telegram. Публикация Mini App требует вашей отдельной HTTPS-установки и настройки бота.

## Ограничения

Один процесс Node с SQLite, без горизонтального масштабирования. Поток можно переподключить в том же процессе; после перезапуска остаётся полученный текст, новая генерация сама не начинается. Файлы до 100 МиБ, изображения до 40 МиБ, PDF/PPTX до 300 страниц/слайдов. OCR использует ваш ИИ; неполные результаты обозначены предупреждением. DOC/PPT требуют отдельно установленного LibreOffice. Общая копия независима от личного оригинала. Модерация выключена по умолчанию и включается оператором.

Закрытые учебные автоматизации и управление выпуском в этот пакет не входят. Документация открытой модели данных, доступа и API — в каталоге `docs` репозитория. Лицензия Apache 2.0; шрифты распространяются со своими OFL.
