# Безопасность

Это учебное ядро и локальная демонстрация. Они не являются готовым сервером для персональных данных или многопользовательского размещения.

## Граница доступа

`Store`, функции контекста и `api.dispatch` не аутентифицируют пользователя и не проверяют его право читать или изменять конкретный курс. Идентификатор курса и фильтр направления не являются правами доступа.

Приложение, которое встраивает ядро, обязано проверять доступ до каждого вызова: для чтения, правки, исторических версий и экспорта. Демонстрационный HTTP сервер должен оставаться на loopback, без публичного туннеля и без реальных материалов.

HTTPS-ссылки хранятся, но ядро их не открывает. Проверка формата ссылки не превращает её в безопасную цель для серверного скачивания. Если приложение добавит такое скачивание, ему нужны отдельные ограничения сети, размеров, времени и перенаправлений.

## Сообщение об уязвимости

Если в опубликованном репозитории включён GitHub Private Vulnerability Reporting, используйте его. Иначе запросите у сопровождающих закрытый канал сообщения. Не прикладывайте секреты, личные данные, рабочую базу или реальные документы в публичный issue.

Полезное сообщение содержит затронутую версию, минимальный вымышленный пример, ожидаемое и фактическое поведение, а также способ воспроизведения. Для демонстрации достаточно временной базы и искусственных блоков текста.

Исправление и публикация новой версии проходят проверку; это описание не означает, что автоматический выпуск уже настроен.
