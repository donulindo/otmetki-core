# Контракт API

Контракт реализован функцией `dispatch(store, method, path, query, body)`. Она возвращает HTTP-статус, полезную нагрузку и тип содержимого, а ошибки выражает исключениями `InvalidInput`, `NotFound` и `Conflict`.

Локальный `Handler` переводит их в HTTP-ответы. Эти маршруты не содержат аутентификацию; встраивающее приложение проверяет доступ до вызова `dispatch`, включая экспорт и старые версии.

## Формат

Запись использует JSON-объект с `Content-Type: application/json`. Неизвестные поля отклоняются. Идентификаторы создаются сервером как строки UUID без дефисов; в путях допускаются строчные латинские буквы и цифры.

В локальном HTTP адаптере тело запроса должно иметь `Content-Length`, быть непустым и не превышать 2 MiB. `Transfer-Encoding` не поддерживается. Этот транспортный лимит может оказаться ниже предельного размера блоков самой библиотеки.

## Маршруты

| Метод и путь | Вход | Результат |
| --- | --- | --- |
| `GET /api/subjects` | — | `{ "subjects": [...] }` |
| `POST /api/subjects` | `code`, `title` | Предмет, 201. |
| `GET /api/courses` | Необязательные query `direction`, `cohort` | `{ "courses": [...] }` |
| `POST /api/courses` | `subjectId`, `direction`, `cohort`, `semester`; необязательный `title` | Курс, 201; без `title` берётся название предмета. |
| `GET /api/courses/{id}/topics` | — | `{ "topics": [...] }` |
| `POST /api/topics` | `courseId`, `title`; необязательный `position` | Тема, 201; позиция по умолчанию 0. |
| `GET /api/courses/{id}/materials` | — | `{ "materials": [...] }`, текущие снимки. |
| `POST /api/materials` | `courseId`, `title`; необязательные `topicId`, `kind`, `status`, `externalUrl`, `blocks`, `warnings` | Материал версии 1, 201. |
| `GET /api/materials/{id}` | Необязательный query `version` | Выбранный снимок; без `version` — текущий. |
| `PUT /api/materials/{id}` | `expectedVersion`; поля правки из списка ниже | Новый снимок, 200. |
| `GET /api/courses/{id}/assignments` | — | `{ "assignments": [...] }` |
| `POST /api/assignments` | `courseId`, `title`; необязательные `topicId`, `kind`, `description`, `startsAt`, `dueAt`, `tentative`, `maxPoints` | Задание, 201. |
| `GET /api/courses/{id}/point-rules` | — | `{ "point-rules": [...] }` |
| `POST /api/point-rules` | `courseId`, `title`; необязательные `topicId`, `description`, `maxPoints` | Правило, 201. |
| `POST /api/context` | Только `{ "materials": [...] }` | Блоки без точных повторов, источники и предупреждения. |
| `POST /api/context.txt` | Тот же выбор | TXT в UTF-8; локальный HTTP адаптер предлагает `context.txt` для скачивания. |

Остальные пути и неподдерживаемые сочетания GET/POST/PUT возвращают 404. Локальный HTTP адаптер отклоняет DELETE/PATCH/HEAD/OPTIONS с 405. Маршрутов удаления, загрузки бинарных файлов, изменения курсов и правки заданий сейчас нет.

## Создание материала

Пример тела; `courseId` нужно заменить идентификатором созданного вымышленного курса:

```json
{
  "courseId": "0123456789abcdef0123456789abcdef",
  "title": "Линейная модель · пример",
  "kind": "lecture",
  "status": "ready",
  "blocks": [
    {"id": "intro", "kind": "text", "text": "Линейная модель описывает зависимость результата от факторов.", "page": 1},
    {"id": "formula", "kind": "formula", "text": "y = a + b x", "page": 1}
  ],
  "warnings": []
}
```

По умолчанию `kind` равен `lecture`, `status` — `ready`, блоки и предупреждения пусты. `ready` означает выбранный статус подготовленного текста, а не подтверждение качества OCR или наличие распознавания: таких процессов в пакете нет.

Ответ:

```json
{
  "id": "abcdef0123456789abcdef0123456789",
  "courseId": "0123456789abcdef0123456789abcdef",
  "topicId": null,
  "version": 1,
  "currentVersion": 1,
  "title": "Линейная модель · пример",
  "kind": "lecture",
  "status": "ready",
  "externalUrl": null,
  "blocks": [{"id": "formula", "kind": "formula", "text": "y = a + b x", "page": 1}],
  "warnings": [],
  "createdAt": "<время создания снимка в UTC>"
}
```

В примере ответа блоки сокращены для читаемости; настоящий ответ содержит все переданные блоки. Поле времени здесь обозначено условно и не является входным значением API.

## Правка материала

Разрешены `title`, `kind`, `status`, `externalUrl`, `blocks`, `warnings`. Непереданные поля сохраняются; переданные массивы полностью заменяют массив предыдущего снимка. `courseId` и `topicId` изменить этим маршрутом нельзя.

```json
{
  "expectedVersion": 1,
  "title": "Линейная модель · исправленный пример"
}
```

После успешного запроса новая версия равна 2. Повторение запроса с `expectedVersion: 1` возвращает 409. Клиент должен прочитать текущую версию и предложить пользователю сверить правки, а не повторять запись с новым номером автоматически.

## Задания и баллы

`kind` задания по умолчанию `homework`, описание пустое, `tentative` равно `false`, а даты и `maxPoints` — `null`. Даты при наличии требуют часового пояса. `maxPoints` обозначает максимум возможных баллов, не личный результат выполнения.

```json
{
  "courseId": "0123456789abcdef0123456789abcdef",
  "title": "Самостоятельная работа · пример",
  "kind": "independent",
  "description": "Вымышленное задание. Дата пока не определена.",
  "tentative": true,
  "maxPoints": 5
}
```

## Контекст выбранных версий

```json
{
  "materials": [
    {"id": "abcdef0123456789abcdef0123456789", "version": 2}
  ]
}
```

Можно выбрать 1–50 записей. Без `version` используется текущий снимок; для воспроизводимого контекста лучше передавать версию явно. Повторные пары `id` + `version` исключаются. Все выбранные материалы должны принадлежать одному курсу.

JSON-ответ имеет поля `blocks`, `duplicateCount`, `warnings`. У каждого итогового блока есть `text`, `kind`, `warnings` и `sources`; каждый источник содержит `materialId`, `title`, `version`, `blockId`, а также `page` или `slide`, если они были заданы. TXT перечисляет выбранные версии, ограничения и источники перед текстом блоков.

## Ошибки локального HTTP адаптера

| Статус | Ситуация |
| --- | --- |
| 400 | Неверное поле, JSON, версия, дата, привязка темы или запрос. |
| 403 | Неподходящий локальный Host или внешний Origin. Это защита локального сервера, а не роль пользователя. |
| 404 | Нет сущности, снимка или маршрута. |
| 405 | HTTP метод DELETE/PATCH/HEAD/OPTIONS не поддерживается. |
| 409 | Совпадающий уникальный код/курс, устаревшая ожидаемая версия или изменённая применённая миграция. |
| 413 | Пустое или слишком большое HTTP тело. |
| 415 | Тип тела отличается от `application/json`. |
| 500 | Локальное хранилище недоступно; внутренние подробности в ответ не включаются. |

Ошибка возвращается как `{ "error": "описание" }`. Локальный адаптер отключает журналы запросов, запрещает кэширование ответов и не разрешает cross-origin запросы. Эти меры не превращают демо в публичный production-сервер.

## API приложения

Все пути ниже требуют серверной сессии. Записи проверяют Origin; ключи и детали внутренних ошибок клиенту не возвращаются.

| Путь | Поведение |
| --- | --- |
| POST /api/auth/local | Локальный ключ оператора; создаёт защищённую сессию |
| POST /api/auth/telegram | Проверяет подпись, срок и числовой Telegram ID подтверждённого профиля |
| GET /api/catalog | Только доступные профилю предметы, аудитории и статусы функций |
| GET/POST /api/materials | Доступная библиотека; личный файл или ссылка с явной публикацией в аудиторию |
| GET/PATCH/DELETE /api/materials/:id | Версии, исправление с ожидаемой version, архивирование |
| GET /api/materials/:id/file?version=N | Оригинал именно выбранной версии после текущей проверки прав |
| GET /api/materials/:id/image | Изображение извлечённого фрагмента; та же проверка доступа |
| POST /api/materials/:id/replace | Обработанный личный candidateId и ожидаемая version; при конфликте — альтернатива |
| GET/POST /api/library | Архив, публикация копии, восстановление и явное объединение альтернатив |
| GET/POST /api/platform | Свой профиль/готовность; оператор управляет подтверждением, членством и правилами |
| GET/POST /api/chats | Только собственные беседы; новые действия зависят от готовности функции |
| POST /api/chat | UIMessage и chatId; SSE поток ответа |
| GET /api/chat/:id/stream | Повторное подключение к живому потоку того же процесса |
| POST /api/chats/:id/regenerate | Явная новая версия ответа на expectedMessageId; прежний ответ сохраняется |
| POST /api/context/export | TXT только из сейчас доступных материалов |
| GET/POST/DELETE /api/events | Ручные события с проверкой аудитории, автора и версии |

Публикация передаёт `{action:"publish",materialId,version,audienceId}`. Ответ 201 содержит общую копию, 202 — ожидание извлечения или модерации. Исправление общей записи при конфликте возвращает 202 и alternativeId; текущая запись остаётся неизменной. Явное объединение передаёт `{action:"resolve",materialId,alternativeId,version,merged?}`. 409 требует перечитать актуальную версию. Недоступный материал возвращает 404, чтобы не раскрывать его существование.
